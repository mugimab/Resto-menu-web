## Resto Menu Web
Resto Menu Web adalah sebuah website yang menampilkan daftar menu restoran secara lengkap dan menarik. Melalui website ini, pelanggan dapat:

- Melihat menu restoran dengan mudah dan praktis.
- Memberikan feedback berupa komentar tentang pengalaman mereka di restoran.
- Melihat feedback pelanggan lain menggunakan fitur View Feedback.
- Menemukan lokasi restoran melalui tombol Our Location yang tersedia di bagian atas halaman.
Dengan fitur-fitur ini, Resto Menu Web memberikan pengalaman digital yang interaktif dan informatif bagi pelanggan.
